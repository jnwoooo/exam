# 0.10.1에서 달라진 것: 백업으로 보이는 폴더와 파일을 처리 대상에서 뺀다

| 항목 | 내용 |
|---|---|
| 읽는 순서 | 26 |
| 작성일 | 2026-11-26 |
| 대상 코드 | `vupdate.py` 0.10.1 |
| 배경 | 패키지 안에 백업해 둔 폴더와 파일이 섞여 있으면, 쓰지 않는 코드에 탐지와 수정이 들고 같은 구조체가 두 번 정의된 것으로 보여 구조 분석이 막힌다 |
| 확인 범위 | Linux, 합성 예제와 공개 코드(Notepad++). 실제 패키지에서는 확인하지 못했다 |

**00~25와 다르면 이 문서가 맞다.** 판정은 이름만 본다. 실제 패키지의 이름 붙이는 방식이 다르면 결과가 달라진다.

---

## 1. 한눈에

| 무엇 | 0.10.0 | 0.10.1 |
|---|---|---|
| 백업으로 보이는 폴더와 파일 | 다른 파일과 똑같이 처리 | **기본으로 뺀다.** 읽지 않고 목록과 까닭을 남긴다 |
| 끄는 방법 | - | `--backups keep` |
| 뺀 것의 목록 | - | `out/backup_excluded.md`, 보고서, 로그, `manifest.csv`(상태 `백업제외`) |

특정 패키지에 맞춘 규칙이 아니라 이름의 일반적인 꼴로 판정한다. 옵션 없이 동작한다.

## 2. 백업으로 보는 이름

### 2.1 확실한 표시: 이름만으로 뺀다

| 표시 | 폴더의 예 | 파일의 예 |
|---|---|---|
| `bak`, `bkup`, `backup`(뒤에 숫자 가능)이 낱말로 들어 있음 | `Backup`, `Src_bak`, `backup_20230101` | `Main_bak.cpp`, `bak_Main.cpp`, `Main_backup.cpp` |
| `백업`, `복사본`, `구버전` | `백업_0312`, `Src - 복사본` | `Main - 복사본.cpp`, `Main_백업.cpp` |
| 복사본의 이름 꼴 | `Copy of Src` | `Copy of Util.cpp`, `Util - Copy.cpp` |
| 폴더 이름이 `old` | `old`, `_old`, `OLD` | - |
| 이중 확장자, 백업 확장자 | - | `Main.bak.cpp`, `Main.old.h`, `Main.cpp.bak`, `Def.orig`, `Main.cpp~` |

낱말은 `_`, `-`, 공백, `.`, 괄호로 나눈 것이다. 그래서 `BackupMgr.cpp`는 걸리지 않는다. 파일 이름 전체가 `Backup`인 것(`Backup.cpp`)도 기능 이름일 수 있어 빼지 않는다.

### 2.2 약한 표시: 표시를 뗀 이름이 같은 폴더에 있을 때만 뺀다

| 표시 | 예 | 조건 |
|---|---|---|
| 끝에 `_old`, `_org`, `_orig`, `_copy`, `_prev`, `_back`, `_save` 등 | `Main_old.cpp`, `Net_old` | 같은 폴더에 `Main.cpp`, `Net`이 있다 |
| 끝에 날짜(8자리 이상, 또는 `_`와 6자리) | `Main_20231010.cpp`, `Main_231010.cpp`, `Net_20231010` | 같은 폴더에 `Main.cpp`, `Net`이 있다. 월과 일이 날짜로 읽혀야 한다 |
| 끝에 `(2)` | `Util (2).cpp` | 같은 폴더에 `Util.cpp`가 있다 |
| 끝에 `Old`, `Org`, `Orig`, `Bak`, `Backup`(대문자로 시작) | `DbOld.cpp` | 같은 폴더에 `Db.cpp`가 있다 |

빼지 않는 예: `Report_2023.cpp`(4자리), `Log_20231010.cpp`(짝이 없음), `Threshold.cpp`, `Callback.cpp`, `FileCopy.cpp`, `Main_new.cpp`, `Main_v2.cpp`, `Main2.cpp`.
`_new`와 `_v2`는 어느 쪽이 지금 쓰는 것인지 이름으로 알 수 없어 건드리지 않는다.

백업 폴더 아래의 것은 모두 백업으로 본다.

## 3. 되살림: 쓰이고 있으면 빼지 않는다

이름이 백업 같아도 다음에 해당하면 그대로 처리한다.

| 경우 | 예 |
|---|---|
| 백업이 아닌 프로젝트 파일(`.sln`, `.vcxproj`, `.vcproj`, `.dsp`)이 그 파일을 참조한다 | `PKG.vcxproj`에 `Src\Cfg_old.cpp`가 있다 |
| 백업이 아닌 소스가 그 헤더를 include 하고, 같은 이름의 헤더가 백업 밖에 없다 | `Main.cpp`가 `Inc_bak/Shared.h`를 include 한다 |

백업 폴더 안의 프로젝트 파일이 참조하는 것은 되살리지 않는다.

## 4. 뺀 파일의 취급

- 읽지 않는다. 탐지, 수정, 구조 분석, 이름 색인에 들지 않는다.
- 스냅샷에 복사하지 않는다. 원본은 언제나 그대로다.
- 파일 표에서 종류는 `backup`, 상태는 `백업제외`이고 까닭이 적힌다.
- 컴파일 검사를 하는 PC에서, 뺀 헤더를 실제로는 쓰고 있었다면 그 소스는 원본부터 "헤더를 열 수 없음"이 되어 컴파일 검사가 미수행으로 기록된다(0.9.2의 동작). 3절의 되살림이 이 경우를 줄인다.

## 5. 판정이 맞지 않을 때

| 상황 | 방법 |
|---|---|
| 백업이 아닌 것을 뺐다 | `--backups keep`으로 판정을 끄고, 진짜 백업은 `--exclude Backup/*`처럼 직접 적는다 |
| 백업인데 빼지 못했다(이름에 표시가 없음. 예: `Src2`) | `--exclude Src2/*` |

- `--backups`는 `skip`(기본)과 `keep` 두 값이다. PowerShell 스크립트는 `-Backups keep`.
- 이어서 실행할 때(`--resume`)는 처음 실행의 값을 쓴다.
- `--package`로 준 폴더 자체의 이름이 백업 같으면 경고만 하고 그대로 처리한다.

## 6. 산출

| 곳 | 내용 |
|---|---|
| `out/backup_excluded.md` | 폴더별 파일 수와 까닭, 폴더 밖의 파일과 까닭, 되살린 파일과 까닭 |
| `out/report.md` | 옵션 줄에 뺀 파일 수(소스 수, 폴더 수), 되살린 수, 끄는 방법. 파일 상태 표에 `백업제외` |
| 로그 | 뺀 수와 백업 폴더(8곳까지), 목록 파일의 위치 |
| `out/manifest.csv` | 파일마다 상태와 까닭 |

백업이 없으면 아무것도 내지 않는다.

## 7. 확인한 것

| 무엇 | 조건 | 결과 |
|---|---|---|
| 이름 판정 | 폴더와 파일 이름 55건(백업 32, 백업 아님 23) | 모두 기대와 같다 |
| 합성 패키지 | 백업 폴더 4곳과 백업 파일 4개, 비슷한 이름의 보통 파일 4개, 되살릴 파일 2개 | 백업 10개만 뺐고, 되살릴 2개와 보통 파일은 처리했다 |
| 구조 분석 | 백업에 같은 이름의 구조체가 또 있는 패키지 | 기본값: 구조체를 써서 바꿨다. `--backups keep`: 두 번 정의된 것으로 보여 바꾸지 못했다(0.10.0과 같다) |
| 공개 코드(Notepad++ 2,509개 파일) | 그대로 | 뺀 파일 0개(백업이 없는 코드에서 잘못 빼지 않았다) |

| 시험 | Linux | 자체 시험 50, 규칙 시험 33, `tests/` 11종 전 항목 통과(`test_v101.py` 16항목) |

## 8. 한계

| 항목 | 내용 |
|---|---|
| 이름만 본다 | 내용을 비교하지 않는다. 이름에 표시가 없는 사본(`Src2`, `Main2.cpp`, `Main_new.cpp`)은 찾지 못한다 |
| 프로젝트 파일이 패키지 밖에 있음 | 프로젝트 참조로 되살리지 못한다. 이름이 백업 같은 진짜 소스가 빠질 수 있으니 `backup_excluded.md`를 확인한다 |
| 프로젝트 파일의 경로에 매크로(`$(SolutionDir)` 등)가 있음 | 그 줄은 읽지 않는다 |
| 프로젝트에 없는 파일을 빼는 것 | 하지 않았다. 이름에 표시가 없으면 프로젝트에 없어도 처리한다 |
| `backup`이 기능 이름인 폴더 | 폴더 이름이 `Backup`이면 백업으로 본다. 그 안의 파일을 프로젝트가 참조하면 되살아나지만, 아니면 빠진다 |
| 줄 단위 한국어 주석(저장소 지침) | 적용하지 않았다. 함수와 구획 단위로 목적 주석을 달았다 |
